# Wifey Homecare Hub

A modern, responsive, and friendly web application for **Hire a Wifey** — an Australian home-help and support service based in Hervey Bay, Queensland.

## Overview
Reclaim your free time — trusted local cleaning, laundry, home maintenance, NDIS, and veteran (DVA) support services.

## Features
- **Mobile-First Responsive Layout:** Clean, intuitive navigation and mobile-optimized booking bar.
- **Service Directory:** Detailed overview of domestic services including Cleaning, Laundry, Ironing, Bed-making, Organising, and Meal Prep.
- **NDIS & Veteran Support:** Verified provider badges and dedicated client intake options.
- **Service Area Guide:** Interactive coverage map and suburban guide for Hervey Bay and surrounding districts.
- **Client Testimonials:** Verified review slider and client rating display.
- **Contact & Inquiry Funnel:** Interactive quotation request and inquiry form with direct location mapping.

## Technology Stack
- **Framework:** React 19, TypeScript
- **Routing & State:** TanStack Router, TanStack Query
- **Styling:** Tailwind CSS, PostCSS
- **Bundler:** Vite, Nitro

## Development & Setup

### Prerequisites
- Node.js (v18+) or Bun

### Installation
```bash
# Install dependencies
bun install
# or
npm install
```

### Running Locally
```bash
# Start development server
bun dev
# or
npm run dev
```

### Building for Production
```bash
bun run build
# or
npm run build
```
