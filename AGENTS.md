# Project Architecture & Guidelines

## Technology Stack
- **Framework:** TanStack Start / React 19 with TypeScript
- **Styling:** Tailwind CSS with utility-first responsive styling
- **Routing:** TanStack Router filesystem and code-based routes under `src/routes/`

## Project Structure
- `src/routes/`: Route definitions and page layouts
- `src/components/`: Reusable UI components
- `src/lib/`: Utility helpers and common types
- `public/`: Static assets and branding icons
